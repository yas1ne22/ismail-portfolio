# Product Case Study Library

This folder contains one portfolio homepage and six separate, self-contained HTML case studies.

## Open the library

Open `index.html` in a modern browser. The homepage contains a preview and an **Open case study** link for every project.

## Separate project pages

1. `projects/nexus/index.html`
2. `projects/timer-gym/index.html`
3. `projects/skinny/index.html`
4. `projects/voicy/index.html`
5. `projects/prepflow/index.html`
6. `projects/promptilo/index.html`

No installation or internet connection is required. All product media, styling, and interactions are embedded in the HTML files.
